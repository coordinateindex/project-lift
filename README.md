Project Lift is a Company Brain hackathon prototype that brings scattered project updates, evidence and decisions into a shared, source-grounded view of work.
The local prototype uses HydraDB for retrieval and knowledge relationships, with a TypeScript/Node.js backend and a lightweight web interface. It records individual updates, checks supporting evidence, and preserves unresolved questions for verification.
Status: working local prototype. This repository currently contains the project overview; source code and run instructions will follow after a security and privacy review.
Demo data is synthetic. Production integrations and deployment are future work.
